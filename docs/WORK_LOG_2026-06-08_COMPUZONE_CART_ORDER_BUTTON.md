# 컴퓨존 장바구니 주문 버튼 탐색 보강

작성일: 2026-06-08

## 증상

- WMS에서 구매 요청 생성 후 컴퓨존 주문/견적 단계가 `장바구니 주문 버튼을 찾지 못했습니다.`로 중단됐다.
- 실패 작업은 장바구니 상품 반영 이후 주문 페이지로 넘어가는 단계에서 멈췄다.

## 원인 추정

- 기존 장바구니 주문 버튼 탐색은 `전체 주문`, `선택 주문`, `주문하기`처럼 텍스트가 노출되는 `a/button/input` 중심이었다.
- 컴퓨존 장바구니 화면은 버튼 라벨이 `전체상품 주문하기`, `선택상품 주문하기`처럼 붙어 있거나 이미지 버튼의 `alt/title`, class/id/onclick 기반으로 노출될 수 있다.
- 이 경우 상품은 장바구니에 들어갔지만 주문 버튼 클릭 후보가 잡히지 않아 실패한다.

## 수정

- `purchase_auto/compuzone_order.py`에 장바구니 주문 버튼 전용 `_click_cart_order_button()`을 추가했다.
- 지원 범위:
  - `전체상품 주문하기`, `선택상품 주문하기`
  - 공백 포함 라벨 `전체 상품 주문하기`, `선택 상품 주문하기`
  - `주문하기`, `구매하기`, `결제하기`
  - 이미지 버튼 `img[alt*='주문']`, `img[title*='주문']`
  - `order`, `buy`, `payment`, `basket_order`, `cart_order` 계열 onclick/href/class/id
- 실패 시 다음 정보를 에러 메시지에 포함한다.
  - 현재 URL
  - 화면 요약
  - 감지된 주문 후보
  - 마지막 클릭 오류

## 검증

- `purchase_auto/compuzone_order.py` 문법 검사를 통과했다.
